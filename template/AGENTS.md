## Working rules

1. Plan non-trivial work and get approval before editing.
2. Reproduce bugs with a failing test before fixing them.
3. Write the minimum code that solves the problem; reuse before adding; no new dependencies
   without approval.
4. Keep changes small and in the style of the surrounding code.
5. Run the build and tests before reporting done; report what you ran.
6. Never commit secrets or run destructive commands.

`.claude/skills/README.md` is the index.

## Installing / updating the harness

This harness is installed by harness-kit. From a clone of the kit:

```sh
./install.sh update /path/to/this/repo      # macOS / Linux
.\install.ps1 update C:\path\to\this\repo    # Windows
```

Locally modified managed files are never overwritten; the new version is written next to
them as `*.harness-new`.
