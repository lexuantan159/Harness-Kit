---
description: Build and open a local HTML dashboard of harness activity (plans, reviews, sessions, issues)
---

1. Run `node .claude/scripts/dashboard.js` - it writes `docs/ai/dashboard.html` and prints the path.
2. Open it: `open` (macOS), `xdg-open` (Linux) or `start` (Windows).
3. Summarise in 3-5 lines: harness version, context docs status, latest reviews and sessions,
   open harness issues.
